# Selected engineering work

## [Wildcard Dex](https://wildcarddex.com) — published

An AI-assisted wildlife identification and collection app published on the [App Store](https://apps.apple.com/us/app/wildcard-dex/id6754198898) and [Google Play](https://play.google.com/store/apps/details?id=com.playoutsidegames.dex).

- Built with Flutter/Dart, Firebase Auth, Cloud Functions, Firestore, SQLite/Drift, and Gemini.
- Kept API keys, validation, parsing, moderation, and safety controls behind authenticated server-side boundaries.
- Added local-first persistence, signed-in backup, bounded retries, safe failure states, observability, accessibility, and localization.

## Sleep Mask — published

A privacy-first adaptive noise machine published on the [App Store](https://apps.apple.com/us/app/sleep-mask-adaptive-noise/id6790191176) and [Google Play](https://play.google.com/store/apps/details?id=com.cools.sleepmask).

- Synthesizes multiple noise profiles and reshapes them in real time using FFT and Bark-band analysis.
- Performs microphone analysis entirely on-device without recording, storing, or transmitting room audio.
- Connects Flutter UI to native mobile audio engines with live visualization, offline use, and sleep timing.

## Slushnet — in development

An owner-controlled agent orchestration system spanning Rust, TypeScript, local coding agents, API models, and MCP.

- Uses typed planner, writer, parallel-review, deterministic-join, and approval stages.
- Supports durable checkpoints, restart recovery, explicit routing, bounded fallback, and inspectable evidence.
- Keeps credentials, spend, protected effects, and authoritative state outside model control.

## SK8 — in development

A modular C#/.NET 8 system with an engine-independent deterministic core.

- Uses schema-driven persistence, replay compatibility, hostile-input handling, and broad automated coverage.
- Includes a bounded AI-assisted development control plane with deterministic gates and explicit human boundaries.
